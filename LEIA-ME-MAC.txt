EMULADOR ENSONIQ ASR-10 PARA macOS (Apple Silicon) — APP E PLUG-IN VST3
=====================================================================

1. Preparar (uma vez)
   - Instala as Command Line Tools da Apple: abre o Terminal e escreve
         xcode-select --install
   - Instala o CMake: com o Homebrew,  brew install cmake
     (ou descarrega o .dmg de https://cmake.org/download/ e copia o CMake para Aplicações).

2. ROMs e disco do OS
   Copia para a pasta "roms" (ao lado deste ficheiro) as ROMs do ASR-10 e a imagem da disquete
   do OS (os353.img). Ficam dentro da app e do plug-in.
   Em alternativa, põe-nas em  ~/Library/Application Support/Ensoniq/ASR10emu/roms

3. Compilar
   No Terminal, dentro desta pasta:
         ./build-mac.sh
   Demora alguns minutos na primeira vez (descarrega o SDK VST3 e o SDL2).
   No fim:
     dist/ASR-10.app   -> arrasta para Aplicações
     dist/asr10-cli    -> ferramenta de linha de comandos
     o plug-in fica instalado em ~/Library/Audio/Plug-Ins/VST3/ASR10.vst3

4. A app
   - Na primeira vez que usares a entrada de áudio, o macOS pede autorização para o microfone.
   - As disquetes e discos SCSI arrastam-se para a janela. O disco do OS é copiado para
     ~/Library/Application Support/Ensoniq/ASR10emu e é essa cópia que é usada/gravada.
   - Discos SCSI por omissão: pasta "scsi" dentro dessa mesma pasta (nomes HD0.img, CD5.iso, ...)
     ou qualquer imagem com mais de 2 MB arrastada para a janela.

5. O plug-in VST3 (instrumento)
   - Aparece como "ASR-10 Emulator" (fabricante ASR10emu) em qualquer anfitrião VST3
     (Cubase, Studio One, Reaper, Bitwig, Ableton Live 11+...). O Logic não usa VST3.
   - Saídas: Main + AUX 1/2/3. Ativa as AUX no anfitrião para as ter separadas (saem do Main).
   - Entrada estéreo (side chain) para samplar / gravar Audio Tracks.
   - MIDI In e MIDI Out (o sequenciador do ASR pode tocar outros instrumentos).
   - "Relógio MIDI do host" (botão no editor ou parâmetro): o ASR recebe o tempo e o
     play/stop do projeto como MIDI clock (põe o ASR a seguir o relógio MIDI no System).
   - Barra do editor: Disquete..., Ejetar, Disco SCSI..., Desligar SCSI, Reset.
     Também se pode arrastar uma imagem para o painel.
   - O projeto guarda o volume e os discos ligados; ao abrir, o ASR arranca de novo com eles
     (os sons carregam-se como num ASR real).

Se o macOS disser que a app "não pode ser aberta": clica com o botão direito > Abrir.

MENUS (barra de menus do Mac)
   File: Open Disk Image (Cmd+O), Eject Disk (Cmd+E), Save Disk Changes (Cmd+S),
         Reset (Cmd+R).
   View: Show Keyboard (Cmd+K) e Options (Cmd+,).
